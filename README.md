# HAT reaction plugin

## Introduction

Plugin for KIMMDY to perform hydrogen atom transfer reactions. Loads a trained tensorflow model to predict energy barriers.

## Installation

* Download
* `pip install -e ./`  or for development: `pip install -r requirements.txt`
* Lint with black

## Available HAT barrier prediction models

* classic_models: Ensemble model trained as described in [Riedmiller et al, 2024](https://doi.org/10.1039/D3SC03922F) with data available at [https://doi.org/10.11588/DATA/TGDD4Y](https://doi.org/10.11588/DATA/TGDD4Y)

* grappa_models: Ensemble model trained as described in [Hartmann et al., 2025](https://www.biorxiv.org/content/10.1101/2025.07.02.662624v1) with data available at https://doi.org/10.17617/3.LWP1PV
